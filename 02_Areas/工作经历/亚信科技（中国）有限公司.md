# 亚信科技（中国）有限公司

## 基本信息

- **总工作年限**：2年
- **亚信任职时间**：2025年8月–2026年8月
- **正式职位**：高级人工智能工程师
- **外部企业客户**：中国联通、中国移动
- **交付方式**：客户内网私有化部署，项目已正式交付
- **数据规模**：每日更新的单表约53万条记录，覆盖客户画像、产品和渠道
- **最终使用规模**：客户内部具体使用部门、用户数和调用量未知，不做推测

## 你在这里做了什么

- 主导企业级 RAG 知识库增强问答系统的核心架构设计
- 构建混合检索：BM25 + BGE + RRF + Cross-Encoder
- 负责数据清洗、字段映射、知识图谱建模与检索接入
- 构建 Neo4j 本体知识建模与关系约束推理
- 设计结构化数据、向量数据与图谱数据三类存储协同架构
- 负责多 Agent 协同工作流、状态管理和数据库设计
- 完成 Qwen + LoRA 领域微调与 vLLM 推理部署
- 设计语义指令映射，把业务规则转为可组合指令单元
- 在客户前线协助完成企业本体搭建与平台使用交付

## 解决的核心问题

纯 RAG 场景下，大模型可能找到部分有依据的理由，却遗漏数据血缘、业务关系和专家判断链路，出现找不到数据、找错数据、目标漂移和推理过程不可验证等问题。

通过企业本体作为语义数据目录和关系约束层，结合三类数据库协同存储、混合检索、实体校验、路径裁剪与 Agent 工作流，将一次性生成式问答改造成可分步执行、可视化检查和可回溯验证的推理流程。

## 关键成果

- 形成面向企业复杂业务推理的 RAG + 知识图谱 + 本体约束 + 多 Agent 应用架构
- 支撑中国联通、中国移动等企业客户的本体搭建与平台交付
- 在客户内网完成私有化部署并正式交付
- 现有材料记录：人工干预减少 70% 以上，响应时间降低 20%；统计周期、基线和样本口径待补充
