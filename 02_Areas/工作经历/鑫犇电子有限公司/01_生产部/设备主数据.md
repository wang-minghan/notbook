# 设备主数据

## 1. 定位

本文件是生产设备实体的主数据入口。设备通过生产执行记录与《产品主数据.md》关联，不把所有设备直接写入产品主数据。

## 2. 主键规则

- **设备编号：主键，必须唯一且稳定。**
- 设备名称、设备类型、型号、吨位和现场位置是属性，不代替设备编号。
- 设备编号应引用现有设备台账；本文件不凭照片或推测新增设备事实。
- 设备是否适配某产品、模具或工艺，必须通过现场资料、设备台账或实际验证确认。

## 3. 字段定义

| 字段 | 是否主键 | 填写规则 | 状态 |
|---|---:|---|---|
| 设备编号 | 是 | 引用设备台账中的稳定编号 | 已确认主键方向 |
| 设备名称 | 否 | 人员易识别名称 | 推荐字段 |
| 设备类型 | 否 | 如冲床、清洗设备等 | 业务值待补 |
| 设备型号 | 否 | 以铭牌或设备资料为准 | 待现场确认 |
| 公称压力/主要参数 | 否 | 仅填写已核实参数，不猜填 | 待现场确认 |
| 安装接口/适配信息 | 否 | 引用核实的适配记录 | 待现场确认 |
| 设备状态 | 否 | 待确认、在用、停用、维修等 | 状态值待确认 |
| 位置 | 否 | 车间/区域/机台位置 | 推荐字段 |
| 来源/证据 | 否 | 铭牌、设备台账、现场核对记录 | 推荐字段 |
| 备注 | 否 | 记录待补事项 | 推荐字段 |

## 4. 与产品及模具的关系

```text
产品编码 + 模具主编号 + 设备编号
→ 生产执行记录
```

设备不是产品的固有属性。只有在生产任务、试模记录或经确认的适配记录中，才能表达产品、模具和设备的实际组合。

## 6. 质量检查

- 设备编号不得重复。
- 设备状态不能替代安全检查、设备验收或操作授权。
- 设备参数必须有铭牌、设备资料或现场核对证据。
- 产品与设备的关系以生产执行记录或适配记录为准。
