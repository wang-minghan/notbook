# 鑫犇电子有限公司岗位操作与知识手册

## 第一版编写基准

### 定位
- 交付形式为 PPT，但按一本可以逐页阅读和现场查用的手册编写。
- 阅读对象默认为已有 5 年以上工龄、熟悉现场工作的员工。
- 不重复讲显而易见的基础动作，重点解决易混淆、易遗漏、做法不统一、异常无法追溯和经验难传承的问题。
- 全文使用通俗、简短、准确的现场语言，不使用低幼式解释。

### 统一要求
- 不使用“SOP”，统一称“流程规范”。
- 不设“通用安全规范”章节；必要风险写在拆模、装模、试模和异常处置等具体流程的“注意”框中。
- 未经公司确认的频次、参数、权限、责任人和审批层级标记为“待确认”。
- 冲裁间隙、热处理硬度等行业经验值只能标记为“参考”，正式值以批准图纸、技术文件或试模确认结果为准。
- PPT 中出现的记录表必须与 Excel 工作表字段一致。

### 每项流程规范的固定结构
1. 适用场景
2. 开始前确认
3. 关键步骤
4. 完成标准
5. 异常处理
6. 使用记录
7. 原理与作用（仅在必要处出现）

### 状态标记
- 【正式标准】：已经公司确认，可直接执行。
- 【参考说明】：帮助理解，不能代替图纸或批准文件。
- 【待确认】：现有资料不足，需公司负责人确认。

### 当前资料边界
现有资料可以支持产品分类、材料易混点、质量检查原则、修机闭环、级进模工位和镶件建模说明。行政制度、实际岗位分工、生产检查频次、审批权限、设备参数等信息不足，第一版保留待确认字段，不擅自编造。

# 第一册 产品与文件标准

## 1. 本册怎么用

这部分不是产品知识百科，主要解决四类现场问题：

1. 同一个型号因为客户不同，材料或结构不同；
2. 产品现场叫法、图纸名称和工单名称不一致；
3. 图纸版本、材料标签或产品资料不完整；
4. 老员工知道怎么分，新员工只能靠问，经验没有变成统一资料。

遇到产品不确定、材料可能混用、图纸版本冲突时，先查本册和配套 Excel。资料仍不能确认时，将产品或材料放入待判区域，不凭记忆继续生产。

## 2. 产品资料统一规则

### 2.1 一个产品必须由五项信息共同确认

- 客户名称
- 产品名称
- 产品型号
- 图号及图纸版本
- 材料规格

只确认其中一两项不够。例如“0825上机壳”并不能唯一确定材料，因为不同客户版本可能分别使用 SPCC、SUS430、SUS304 或 C2800。

> 【原理与作用】型号说明产品系列，不一定说明客户版本。把客户、型号和材料放在一起确认，是为了防止外形相近的产品被当成同一种产品。

### 2.2 现场叫法可以保留，但正式记录只用统一名称

现场习惯叫法填在“现场常用名”字段，工单、首件、巡检、修机报告和备品台账使用“产品名称”或“零件名称”。同一对象不能在不同记录里随意换名字。

### 2.3 产品编码

产品编码用于在表格之间关联同一产品。编码规则第一版建议为：

`客户简称-型号-零件简称`

示例：`LDW-1027-上机壳`。

该规则属于【待确认】，公司如已有正式料号，应直接使用现有料号，不再另造一套编码。

## 3. 产品主数据表

产品主数据是产品资料的唯一入口。生产任务确认、首件检查、巡检和异常处理都从这里引用，不在各张表里重复维护不同版本的材料数据。

### 3.1 字段

| 字段 | 填写要求 |
|---|---|
| 产品编码 | 每个客户版本产品唯一；优先使用公司现有料号 |
| 客户名称 | 使用公司统一简称或全称，不混用多个简称 |
| 产品名称 | 与有效图纸一致 |
| 现场常用名 | 记录现场习惯叫法，可为空 |
| 产品型号 | 如 0625、0825、1027、1234 |
| 图号 | 与有效图纸一致 |
| 图纸版本 | 填正式版本号；无版本号时标待确认 |
| 材料牌号 | 如 SPCC、SUS430、SUS304、SUS301、C2800 |
| 材料厚度 | 单独填写，不与料宽混在一个字段 |
| 材料宽度 | 单独填写 |
| 单重参考 | 必须注明单位；照片识别数据未复核前标待确认 |
| 模具编号 | 与模具台账一致 |
| 状态 | 在用、试制、停用、待确认 |
| 生效日期 | 当前资料开始执行的日期 |
| 备注 | 特殊表面处理、客户要求或其他说明 |

### 3.2 完成标准

- 每个在产品只有一条当前有效记录；
- 客户、型号、零件和材料能够对应；
- 厚度、宽度和单重均有单位；
- 图纸版本和模具编号可以追溯；
- 模糊照片识别数据不得标成正式值。

## 4. 已知产品范围

现有知识库显示，公司产品主要包括：

- 上机壳、下机壳；
- 磁扣、磁碗、磁栅；
- 制动片；
- 转子片；
- 隔板、极片、垫片；
- 盖板、支架。

现有资料涉及 LDW、DC、安和等客户或系列，以及 0515、0518、0525、0620、0625、0825、0832、1027、1234、080935 等型号。该范围来自现有资料，不代表完整产品目录。

## 5. 易混材料对照

### 5.1 使用方法

易混材料表不是采购标准，也不代替图纸。它用于提醒现场：哪些产品不能只看型号或外观判断。正式领料和生产仍以当前有效图纸、工单及批准材料资料为准。

### 5.2 已知易混点

- 同一型号，不同客户可能使用不同材料；
- 同一客户的上机壳、下机壳、磁栅和制动片材料不同；
- 0825、0832系列客户版本较多，不能只看型号；
- 制动片存在硬料、软料和料宽差异；
- SPCC、SUS430、SUS304、SUS301、C2800必须连同厚度和宽度确认。

### 5.3 易混材料表字段

| 字段 | 用途 |
|---|---|
| 对照编号 | 每组易混对象唯一编号 |
| 产品编码 | 关联产品主数据 |
| 客户名称 | 区分客户版本 |
| 产品名称 | 明确零件 |
| 产品型号 | 明确系列 |
| 正确材料牌号 | 当前有效标准 |
| 材料厚度 | 独立字段 |
| 材料宽度 | 独立字段 |
| 易混对象 | 最容易混淆的产品或材料 |
| 主要区别 | 标签、厚度、宽度、硬软状态或结构差别 |
| 核对依据 | 图纸、材料标签或批准文件 |
| 混用后果 | 报废、尺寸异常、性能异常等 |
| 状态 | 正式、参考、待确认 |

## 6. 图纸及文件版本管理流程规范

### 6.1 适用场景

- 新图纸首次投入使用；
- 客户图纸、工艺要求或材料发生变更；
- 现场纸质图纸与电子文件不一致；
- 修模后需要更新工位图、零件图或备品资料。

### 6.2 开始前确认

- 文件名称和文件编号；
- 产品编码或模具编号；
- 当前版本和新版本；
- 生效日期；
- 变更内容；
- 受影响的工单、库存、在制品和模具资料。

### 6.3 关键步骤

1. 新文件未经确认，不直接替换现场文件；
2. 确认变更影响范围，特别检查材料、关键尺寸、表面处理和模具工位；
3. 更新文件版本清单；
4. 发放新版本，并记录发放位置；
5. 回收或明显作废旧版本，避免新旧文件同时在现场使用；
6. 需要培训或重新做首件时，在变更记录中写明；
7. 电子图纸、产品主数据和相关表格同步更新。

### 6.4 完成标准

- 现场只能找到当前有效版本；
- 文件版本清单与现场文件一致；
- 受影响人员知道变更内容；
- 旧版本已回收或明确标识作废；
- 与变更相关的首件、试模或确认记录可以追溯。

### 6.5 异常处理

发现新旧版本冲突时，先暂停使用有争议的文件，标记受影响产品或工单，交由【待确认：公司指定人员】确认。不得自行选择“看起来更合理”的版本。

### 6.6 使用记录

使用《文件版本清单》，字段包括：文件编号、文件名称、关联对象、版本号、生效日期、变更内容、发放位置、旧版处理、确认人、状态。

# 第二册 生产部门流程规范

> 本册默认读者熟悉冲压生产，不重复讲设备按钮、量具基础和日常动作。重点统一开工确认、材料核对、首件、巡检、换型、隔离和异常追溯。

## P-01 生产任务确认流程规范

### 适用场景
新工单开工、插单、续单、换班接单，以及图纸、材料或交期发生变化时。

### 开始前确认
查《03任务确认》，确认工单号、产品编码、客户、产品名称、型号、图号及版本、计划数量、交期、材料规格、模具编号、设备编号和上次异常。

不要求员工重新抄一遍工单。确认的重点是：

- 工单上的产品与现场实物、图纸名称是否一致；
- 图纸版本是否为当前有效版本；
- 材料牌号、厚度、宽度是否与产品主数据一致；
- 模具编号是否对应本次产品；
- 上次停机、修模或质量异常是否已经关闭。

### 关键步骤
1. 用产品编码查《01产品主数据》，不要只靠型号判断。
2. 对照当前有效图纸，确认图号和版本。
3. 对照材料标签，确认牌号、厚度和宽度。
4. 对照模具标识，确认模具编号。
5. 查看上次异常或修机记录；未关闭的问题写入“上次异常”。
6. 勾选“三项一致确认”：实物与资料一致、材料一致、模具一致。
7. 信息不一致时停止下达，不凭经验选择其中一个版本。

### 完成标准
产品、图纸、材料、模具和设备能够相互对应；未关闭异常已写明；确认人可追溯。

### 异常处理
- 图纸版本冲突：暂停，交由【待确认：公司指定人员】确认。
- 产品名称不同但外形相同：按产品编码和图号确认，不按外观合并。
- 上次异常未关闭：不得直接按正常状态开工，先确认恢复条件。
- 工单缺少材料或模具信息：补齐后再确认。

### 使用记录
《03任务确认》。同一工单换产品、换材料、换模具或图纸版本后，应重新确认。

## P-02 领料与材料核对流程规范

### 适用场景
新工单领料、换卷、使用余料、退料后重新领用，以及材料标签破损或信息不全时。

### 开始前确认
- 工单号和产品编码；
- 材料牌号、厚度、宽度；
- 材料批次；
- 领料重量；
- 标签是否完整。

### 关键步骤
1. 先查产品主数据，再看材料标签；不能先拿“看起来一样”的料。
2. 材料牌号、厚度、宽度逐项核对，三个字段不能合并判断。
3. 对0825、0832、1027、1234及制动片等易混对象，再查《02易混材料》。
4. 余料必须保留可追溯标签；没有标签的余料按待判材料处理。
5. 换卷时记录新批次，旧批次剩余产品与新批次产品保持可区分。
6. 退料时记录余料重量和原批次，不重新编造批次。

### 完成标准
材料标签完整，牌号、厚度、宽度和批次可追溯；工单与材料标准一致；余料有明确身份。

### 原理与作用
同型号不同客户可能使用不同材料。材料外观接近并不代表性能相同，混料常常要到冲压、表面处理甚至客户使用时才暴露，追溯成本远高于领料时核对。

### 异常处理
- 无标签或标签模糊：隔离，禁止凭颜色、硬度手感或记忆认料。
- 标签与产品主数据不一致：停止领用，保留原标签并上报。
- 已使用后发现疑似混料：立即停止，按批次和开始使用时间隔离产品，建立异常记录。
- 同一容器混入两批材料：整容器待判，不能只挑出明显不同部分。

### 使用记录
《04领料核对》。字段包括工单、产品编码、材料牌号、厚度、宽度、批次、领料重量、余料重量、标签状态、核对结果和核对人。

## P-03 开机前关键确认流程规范

### 适用场景
新工单开机、换模后开机、修模后恢复、长时间停机后重新开机、交接班后首次开机。

### 开始前确认
- 生产任务已经确认；
- 模具安装状态和模具编号正确；
- 材料及送料方向正确；
- 上次异常和维修状态明确；
- 首件所需图纸、检具和记录已准备。

### 关键步骤
1. 清空接料容器、工作台和标识牌上的上一产品，防止混装。
2. 对照模具编号，不用“这套模一直做这个产品”代替确认。
3. 确认送料方向、料带正反面和步距参数来源。
4. 修模后检查修机报告和试模结论，确认允许恢复生产。
5. 低速或点动观察首段料带，确认送料、导正、卸料和废料排出状态。
6. 完成首件前，产品不得转入正常合格品区域。

### 完成标准
现场无上一产品残留；模具、材料、参数来源明确；送料和废料排出正常；具备做首件的条件。

### 异常处理
发现异响、卡料、导正不顺、卸料不顺或模内有异物时立即停止。不得为了“先冲几下看看”连续运行。

### 使用记录
关键确认结果记录在《03任务确认》的备注或上次异常栏；发生异常时转《07异常处理》。如公司需要独立开机检查表，表单编号【待确认】。

## P-04 首件确认流程规范

### 适用场景
新工单、换模、换料、换图纸版本、修模后恢复、关键参数调整后，以及【待确认：公司规定的其他情形】。

### 开始前确认
- 当前图纸和版本；
- 产品编码和材料规格；
- 需要检查的尺寸、外观和工艺要求；
- 检具状态；
- 上次异常涉及的重点位置。

### 关键步骤
1. 首件记录按“一个检查项目一行”填写，不能把多个尺寸塞在同一格。
2. 检查项目来自有效图纸、产品主数据和已确认的检验要求。
3. 图纸带“★”的尺寸优先检查，并写明图纸标准、实测值和单位。
4. 外观检查包括毛刺、变形、压伤、划痕、裂纹、漏冲等与该产品有关的项目。
5. 涉及材料、表面处理、盐雾或焊接要求时，确认对应资料，不把尺寸合格等同于全部合格。
6. 首件不合格时，记录真实结果，不先改记录再调整设备。
7. 调整后重新取样检查，并保留最终确认结果。

### 完成标准
检查项目有来源；图纸标准、实测值、单位和检具记录完整；结果明确为合格、不合格或待判；确认人可追溯。

### 异常处理
- 实测值超差：停止量产，调整后重新做首件。
- 图纸无法判断或检具不适用：标待判，不以目测代替。
- 首件合格但材料或版本不一致：首件仍判无效，先解决资料问题。
- 修模后原问题合格但出现新问题：不得只确认维修点，需检查受影响关联位置。

### 使用记录
《05首件检查》。检查频次、抽样数量和确认权限均为【待确认】，正式值由公司批准。

---

## P-05 生产中检查流程规范

### 适用场景
正常量产、换卷后、停机再启动后、模具或设备状态发生轻微调整后。

### 开始前确认
首件已确认；巡检项目和图纸标准明确；量具可用；上一巡检结果和异常状态清楚。

### 关键步骤
1. 按《06生产巡检》逐项记录，不只填写“正常”。
2. 重点关注关键尺寸、毛刺、孔位、折弯/成型状态及上次异常位置。
3. 同一尺寸接近公差边界并持续向同一方向变化时，按趋势异常处理，不等到正式超差。
4. 换卷、短暂停机、清模或参数微调后，检查结果要能与变更时间对应。
5. 发现不合格时，以“上一次已确认合格的时间或数量”为追溯起点，隔离此后产品。
6. 处理后记录处理结果；需要修模或试模时转入对应流程。

### 完成标准
记录有时间、数量、标准值和实测值；异常能够确定隔离起点；处理结果与恢复条件明确。

### 原理与作用
巡检不仅判断当下这件产品是否合格，还用于观察模具磨损和尺寸变化趋势。只写“合格”会丢掉趋势信息。

### 异常处理
- 单件异常且原因不明：先扩大检查，相关批次待判。
- 连续偏移：停止并检查模具、送料、材料和测量条件。
- 毛刺突然增加、漏冲、裂纹或异响：立即停机，不按普通尺寸波动继续观察。
- 无法确定追溯起点：从最近一次有证据的合格记录之后全部隔离。

### 使用记录
《06生产巡检》及必要时《07异常处理》。具体巡检频次由产品要求和公司制度确定，第一版标【待确认】。

---

## P-06 换料、换模与换产品流程规范

### 适用场景
换卷、材料批次变化、更换模具、同设备切换产品、同型号切换客户版本。

### 关键步骤
1. 完成上一批产品数量和状态记录。
2. 清理接料箱、周转箱、工作台、设备出口和标签中的上一产品。
3. 余料重新标明材料牌号、厚度、宽度、批次和剩余重量。
4. 新任务重新核对产品编码、图纸版本、材料和模具编号。
5. 替换现场产品标签、样品和检验资料，旧资料移出使用位置。
6. 换模、换材料或关键参数变化后重新做首件。
7. 同型号不同客户切换时，按换产品处理，不因外形相近省略步骤。

### 完成标准
现场不存在上一产品或旧标签残留；新旧材料和产品可区分；首件已经确认。

### 异常处理
发现混装、标签不明或新旧产品无法区分时，相关容器全部转待判；不得靠挑选外观恢复为合格品。

### 使用记录
任务确认、领料核对、首件检查；发生混装时使用异常处理记录。

---

## P-07 不良品与待判品处理流程规范

### 适用场景
发现尺寸、外观、材料、版本或身份异常，以及暂时无法确定是否合格时。

### 状态定义
- **合格**：有明确标准和检查证据证明符合要求。
- **不合格**：有明确标准和检查证据证明不符合要求。
- **待判**：资料、测量条件或判定权限不足，暂时不能下结论。
- **返工后待复检**：已经处理，但尚未重新确认。

### 关键步骤
1. 先隔离实物，再补记录；不要边生产边等结论。
2. 标识产品编码、工单号、数量、发现时间、异常现象和状态。
3. 确定隔离范围，不能只拿走发现异常的单件。
4. 待判品由【待确认：有判定权限的人员】处理。
5. 返工后重新检查，原标签和处理记录保留。
6. 只有确认完成后才能更改状态和转移区域。

### 完成标准
实物状态、区域标签和记录一致；数量可核对；判定依据和处理结果可追溯。

### 异常处理
标签脱落、不同状态混放或数量对不上时，按风险更高的状态处理，先全部待判再核清。

### 使用记录
《07异常处理》，必要时关联首件、巡检、修机和试模记录。

---

## P-08 常见生产异常处理流程规范

### 通用处理顺序
1. **停**：可能继续扩大损失或伤模时立即停止。
2. **隔**：隔离从最近一次有证据的合格点之后的产品。
3. **记**：记录现象、时间、数量、模具和工位，不先猜原因。
4. **查**：按材料、送料、模具、设备、测量和操作变化检查。
5. **验**：处理后重新首件或试模，达到恢复条件才生产。

### 异常卡1：毛刺突然增大
- 先做：停机并保留异常样件。
- 检查：冲头/凹模刃口、间隙状态、松动、材料厚度和送料位置。
- 隔离：最近一次合格巡检之后的产品。
- 恢复：维修或调整后首件合格；必要时关联修机报告。

### 异常卡2：尺寸连续偏移
- 先做：暂停，核对测量方法和量具后复测。
- 检查：材料批次、送料步距、模具松动、成型件磨损和设备状态。
- 隔离：从趋势开始变化的记录点起；无法判断时从上次合格点起。
- 恢复：实测稳定，首件和必要的连续样件合格。

### 异常卡3：漏冲、少孔或孔位异常
- 先做：立即停机，不继续观察。
- 检查：冲头折断、卡料、导正、送料步距和料带方向。
- 隔离：从上次确认合格之后全部隔离。
- 恢复：模内清理、维修完成，首件确认关联孔位和后续工位。

### 异常卡4：料带跑偏或送料不到位
- 先做：停机，保留当前料带位置。
- 检查：导正孔、导正销、送料参数、料带毛刺、材料宽度和导料状态。
- 禁止：强行连续冲压或手扶料带运行。
- 恢复：点动/低速验证送料和导正正常，再做首件。

### 异常卡5：产品卡模、卸料不顺或异常声音
- 先做：立即停止，按现场停机要求处理。
- 检查：冲头、卸料板、弹簧、等高套筒、废料和产品粘附。
- 禁止：带故障连续冲压；未经确认直接用硬物敲击关键刃口。
- 恢复：异常原因已经处理，手动/低速验证后首件合格。

### 异常卡6：疑似混料或混批
- 先做：停止使用该材料，隔离材料、在制品和已产产品。
- 检查：标签、领料记录、批次切换时间、余料和产品流向。
- 禁止：仅凭外观挑料或重新贴标签掩盖原批次。
- 恢复：材料身份确认，受影响产品完成判定。

### 使用记录
统一使用《07异常处理》：异常编号、工单、产品、模具、工位、现象、发现时数量、隔离范围、临时处理、原因、措施、恢复条件、结果、确认和关闭状态。

# 第三册 模具部门流程规范

> 本册不是模具入门教材。默认读者熟悉拆装、测量、试模和修模，重点把工位、镶件、模型、图纸、维修和备品连成一套可追溯资料。

## M-01 级进模资料标准

每套在用模具至少建立以下资料：

1. 模具编号及对应产品编码；
2. 模具总图和当前版本；
3. 料带排样图，标明送料方向、步距和工位号；
4. 工位说明和各工位加工内容；
5. 模具零件及镶件台账；
6. SolidWorks零件、装配体和工程图；
7. 试模记录；
8. 修机报告；
9. 备品库存记录。

资料缺失不等于模具不能生产，但会导致维修、复刻和交接继续依赖个人记忆。第一版先补影响最大、最常维修的工位和零件，不要求一次补齐所有旧模具。

### 工位统一

推荐工位号使用 `OP10、OP20、OP30……`，中间留号便于插入工位。公司现有成熟编号优先保留，禁止同一套模具同时使用两套工位编号。

扁平马达类级进模典型工位顺序：

| 工位示例 | 主要加工内容 | 常见镶件 |
|---|---|---|
| OP10 | 导正孔、预冲孔 | 细圆冲、凹模镶套 |
| OP20 | 小孔、端子槽 | 小圆冲、异形方冲 |
| OP30 | 外形预切 | C型开口筒式镶件 |
| OP40 | 压印、压筋、预成型 | 带定位凸台成型冲 |
| OP50 | 折弯、翻孔 | 台阶式圆冲、成型镶件 |
| OP60 | 整形 | 成型镶件 |
| OP70 | 落料、分离 | 大外形冲、凹模镶块 |

这是工位结构示例，不是所有模具的固定编号。

## M-02 镶件识别与数据记录流程规范

### 适用场景
旧模具资料补录、新镶件建档、维修更换、备品复刻和建模前数据采集。

### 关键原则
- 正式名称、现场常用名可以同时记录，但零件ID唯一；
- 测量值、设计值和磨损后现状不能混写；
- 每个镶件必须关联模具编号和工位号；
- 尺寸不足时标待确认，不凭相邻零件推测；
- 配合间隙和热处理要求以批准图纸、技术文件或试模结果为准。

### 镶件识别要点

#### 1. 圆形小孔冲头
- 识别：细长圆柱，头部平直。
- 作用：冲产品小孔或料带导正孔。
- 必记：刃口直径、刃口高度、总长、固定段、挂台。
- 易错：与导正销混淆；导正销前端通常有导入锥度，不承担正常冲裁。

#### 2. 台阶式圆冲
- 识别：头部较细，下段加粗，可能带R过渡。
- 作用：沉孔、翻孔、拉伸、半冲孔或局部成型。
- 必记：头部尺寸、台阶高度、R角、挂台。

#### 3. C型开口筒式镶件
- 识别：筒形主体带轴向开口槽。
- 作用：预切外圆或大圆弧，同时避让料带载体。
- 必记：外圆、开口槽宽深、刃口和挂台。
- 易错：开口方向没有关联送料方向，装反后会直接影响载体。

#### 4. 异形方冲/扁冲
- 作用：冲长槽、方缺口、端子槽或直边切边。
- 必记：截面长宽、异形轮廓、刃口、挂台及方向基准。

#### 5. 带定位凸台的成型冲
- 作用：预压、压筋、压印或折弯前预成型。
- 必记：主体、顶部凸台直径和高度、方向特征。

#### 6. 六角/多边形成型镶件
- 必记：对边尺寸、外接圆、刃口高度和方向基准。

#### 7. 凹模镶块
- 作用：承接冲头并形成对应型腔，磨损后单独更换。
- 必记：外框、型腔轮廓、高度、固定孔和装配方向。

#### 8. 导柱、导套
- 作用：保证上下模合模导向，减少偏载和啃模风险。
- 必记：导柱外径、长度；导套内径、压入段和配合状态。

#### 9. 弹簧与等高套筒
- 作用：提供卸料力、限制卸料板行程和保持平行。
- 必记：规格、自由高度/套筒高度、螺纹和安装位置。

#### 10. 导正销
- 作用：进入导正孔，修正送料累积误差。
- 必记：工作直径、导入锥度、总长、固定方式和工位。

### 使用记录
《08模具零件》；零件ID、模具编号、工位号、名称、类型、材料、热处理、外形、刃口、挂台、特征、间隙、装配位置、图纸、版本、备品、位置、状态和备注。

## M-03 镶件测量与数据采集流程规范

### 适用场景
无完整图纸的旧镶件补录、磨损分析、复刻备品和建模。

### 开始前确认
- 零件ID、模具编号和工位号；
- 零件是否为使用件、磨损件、合格备品或报废件；
- 测量基准和方向标记；
- 现有图纸或装配关系。

### 关键步骤
1. 清洁零件，先拍整体和方向照片。
2. 选择稳定基准面，记录送料方向、上/下模方向和挂台方向。
3. 先测总长和最大外形，再测固定段、挂台、刃口和局部特征。
4. 异形轮廓优先从排样图、线切割文件或投影测量获取，不用几个手工点拼出“看起来差不多”的轮廓。
5. 磨损件同时记录“现状测量值”和“设计值待确认”，不得把磨损后的尺寸当设计尺寸。
6. 与配合件复核装配关系；必要时记录模板孔或凹模尺寸。
7. 第二人复核关键尺寸和方向【复核人由公司待确认】。

### 完成标准
数据可定位到具体模具、工位和零件；基准与方向清楚；设计值和现状值区分；关键尺寸有复核依据。

### 异常处理
尺寸无法可靠测量时，保留照片、测量条件和疑点，标待确认。不得为了完成台账填写猜测值。

---

## M-04 SolidWorks建模流程规范

### 适用场景
建立或补充镶件零件、模具装配、加工工程图和BOM。

### 输入资料
产品图、料带排样、模具总图、测量记录、模具/工位/零件编号、材料及热处理要求。

### 关键步骤
1. 建立项目文件夹，按模具编号收口，不把正式文件散放个人桌面。
2. 统一单位、原点、送料方向和上/下模方向。
3. 先建立料带排样草图，确定步距和各工位轮廓，作为总基准。
4. 建立模座、固定板、垫板、卸料板和下模板等装配基准。
5. 按工位建立镶件；文件名包含零件ID和零件名称。
6. 冲头与固定板孔同轴，安装面按实际结构重合；凹模镶块对应下模板槽；导正销关联卸料板。
7. 检查合模状态、冲头与凹模关系、卸料板行程和相邻工位干涉。
8. 输出工程图；关键尺寸、材料、热处理和版本与台账一致。
9. 生成BOM，并与《08模具零件》核对零件ID、数量和状态。
10. 变更后更新版本及变更说明，不覆盖掉无法追溯的旧版。

### 建模注意
- 挂台方向在同类零件中统一；
- 刃口高度不是越长越好，正式值按批准图纸或试模确认；
- 异形轮廓优先引用排样草图，减少重复描图误差；
- 弹簧与等高套筒需验证卸料板行程；
- 间隙经验值只可作为参考说明，不直接写成所有材料通用标准。

### 完成标准
装配无非设计干涉；工位、方向和文件名清楚；工程图/BOM/台账字段一致；版本可追溯。

---

## M-05 拆模、检查与装配流程规范

### 适用场景
计划维修、异常维修、清洁检查和更换镶件。

### 拆模关键步骤
1. 拆前记录模具编号、工位、故障现象及当前状态。
2. 拍摄整体、局部和方向照片，特别是相似镶件、垫片和弹簧位置。
3. 按工位摆放拆出零件，不同工位不混盘。
4. 对带预压力部件按实际结构卸力后拆卸。
5. 刃口、导正销和精密配合面单独防护。

### 检查重点
- 冲头、凹模的崩刃、磨损和裂纹；
- 导柱导套的拉伤和间隙状态；
- 卸料板、弹簧、等高套筒的行程和受力；
- 螺丝松动、垫片变化和定位失效；
- 废料堵塞、粘料和送料擦伤痕迹。

### 装配关键步骤
1. 按照片、工位和零件ID复位。
2. 统一确认挂台、刃口、开口槽和异形件方向。
3. 检查冲头与凹模对应，不用强行合模验证方向。
4. 按结构要求紧固，垫片组合如有变化必须记录。
5. 手动或低速验证导向、卸料和合模状态。
6. 维修后进入试模流程，不直接恢复量产。

### 注意
拆装涉及预压力、锐利刃口和重件时，按现场已确认的停机、吊装和防护要求执行；第一版不另造安全制度。

### 完成标准
零件无混装、漏装和方向错误；运动正常；维修变化已进入修机报告；具备试模条件。

## M-06 试模流程规范

### 适用场景
新模具、重大维修、更换关键镶件、尺寸调整、工位结构变更和异常恢复验证。

### 开始前确认
模具编号、产品编码、材料牌号及厚度、设备编号、试模目的、涉及工位、批准图纸和上次问题。

### 关键步骤
1. 明确本次试模要验证的问题，不能只写“试一下”。
2. 记录调整前状态和数据。
3. 低速观察送料、导正、冲裁、成型、卸料和废料排出。
4. 按工位保留有代表性的料带或样件。
5. 调整一次记录一次，不把多次调整合成一句“已修好”。
6. 记录调整前数据、调整内容和调整后数据，单位明确。
7. 检查本工位结果，同时复核可能受影响的前后工位。
8. 给出明确结论：通过、继续调整、转修模或待确认。

### 完成标准
问题位置、调整内容、前后数据和样件结果完整；结论能够支持是否恢复生产。

### 异常处理
出现啃模、断冲、严重卡料或方向不明时立即停止，不以继续冲压寻找原因。

### 使用记录
《09试模记录》。Excel中有两条黄色虚拟示例，只用于说明填写方式。

---

## M-07 修模流程规范

### 通用顺序
1. 根据产品异常定位工位；
2. 保留故障样件、料带和维修前照片；
3. 拆检并记录真实故障，不先写结论；
4. 确认维修方式和更换零件；
5. 装配后试模；
6. 关联试模编号并关闭修机报告。

### 常见故障检查方向

| 故障表现 | 优先检查 | 禁止做法 |
|---|---|---|
| 毛刺增大 | 冲头/凹模刃口、松动、材料厚度、送料位置 | 只修磨不记录修磨量 |
| 冲头折断/崩刃 | 导正、偏载、间隙、刃口长度、材料异常 | 只换新冲头不查原因 |
| 啃模 | 导柱导套、模板定位、冲头/凹模同轴、装配方向 | 强行合模 |
| 折弯尺寸不稳 | 成型镶件、垫片、回弹、材料批次、压料状态 | 只凭单件调整 |
| 卸料不顺 | 卸料板、弹簧、等高套筒、粘料、冲头表面 | 连续冲压“磨顺” |
| 导正异常 | 导正孔、导正销、送料步距、料带跑偏 | 加大力度强行导正 |
| 产品粘模 | 刃口/成型面、润滑、卸料、表面状态 | 用会伤刃口的方式硬撬 |

### 完成标准
故障原因与处理方式有证据；更换件可追溯；试模结果验证原问题和关联影响；报告关闭。

---

## M-08 修机报告流程规范

### 适用场景
任何影响产品、停机、需要拆模或更换模具零件的维修。

### 必须记录
- 报告编号、日期、模具、产品和工位；
- 故障现象和停机时数量；
- 产品隔离范围；
- 测量数据和维修前照片；
- 原因分析；
- 处理方式和更换零件ID；
- 维修后照片；
- 关联试模编号和结果；
- 后续提升、维修人、确认人和关闭日期。

### 关键要求
1. 修机报告必须挂产品图、料带图或问题位置照片，至少能看出故障发生在哪里。
2. “冲头坏了”“尺寸不行”不算完整故障描述，要写清工位、特征和现象。
3. 原因分析与处理方式分开写；“更换冲头”是处理，不是原因。
4. 更换件必须填写零件ID；无编号时先建立临时标识并补台账。
5. 试模未通过，报告状态不能写已关闭。
6. 可提升点应进入具体资料更新、备品补充或检查项，而不是停留在一句建议。

### 使用记录
《10修机报告》。Excel中有两条黄色虚拟示例，仅说明填写方法。

---

## M-09 模具备品管理流程规范

### 适用场景
新��备品、维修领用、库存补充、盘点和报废。

### 关键步骤
1. 备品以零件ID关联具体模具和工位，不用“1027冲头一支”这种模糊名称。
2. 入库前核对图纸版本、关键尺寸、材料/热处理要求和外观状态。
3. 防锈、防磕碰包装；外包装标零件ID、模具编号和工位号。
4. 领用时记录日期和用途，维修报告引用同一零件ID。
5. 当前库存达到或低于最低库存时标补充状态。
6. 盘点发现账物不一致，先更正实物状态，再查领用记录。
7. 报废件保留照片；对有分析价值的断件按公司要求留样【待确认】。

### 完成标准
台账数量与实物一致；备品能快速找到；版本和适用模具明确；领用后能触发补充。

### 使用记录
《11模具备品》；库存记录号、零件ID、模具、工位、名称、最低库存、当前库存、单位、位置、最近入库/领用、补充状态和负责人。

# 第四册 行政管理流程规范

> 行政部分按50人规模工厂的实际需要编写，不套用大公司制度。工资算法、处罚、审批层级、法定时限和权限未经公司确认，不在第一版擅自规定。

## H-01 入职资料办理流程规范

### 适用场景
新员工报到、返聘或重新入职。

### 关键步骤
1. 核对本人身份和公司要求的入职资料。
2. 建立员工编号【编号规则待确认】，避免重名员工混档。
3. 记录部门、岗位、入职日期、联系方式和紧急联系人等必要信息。
4. 劳动合同、相关告知和其他法定资料按现行法律及公司确认制度办理。
5. 发放物品和资料时记录名称、数量及签收。
6. 安排公司、部门和岗位相关培训；未完成岗位确认前不得把员工记录为已独立上岗。
7. 纸质和电子资料归入同一员工档案索引。

### 完成标准
员工身份明确；必需资料齐全或有缺件清单；劳动关系文件状态清楚；发放物品、培训和岗位安排可追溯。

### 异常处理
资料缺失、身份信息不一致或合同状态不清时，按公司确认规则处理并记录，不能用口头承诺代替缺件状态。

### 使用记录
员工档案、物品签收、培训记录。具体资料清单、合同签署权限和完成时限为【待确认】。

---

## H-02 带教与岗位确认流程规范

### 适用场景
新员工、转岗、长期离岗后返岗、设备或流程有重大变化。

### 关键步骤
1. 明确带教岗位、带教人和需要掌握的流程规范。
2. 培训内容以当前有效手册、图纸和表单为准，不只靠口头经验。
3. 记录已讲内容、实际练习和发现的问题。
4. 考核分为“知道要求”和“能按要求完成”，不能只凭签到判定通过。
5. 未通过的项目明确补训内容，再次确认。
6. 岗位确认结果写入培训记录；确认权限【待确认】。

### 完成标准
员工能找到并使用相关流程规范和表格；关键易错点已经讲清；考核结果和岗位确认结果可追溯。

### 使用记录
《13培训记录》：培训编号、日期、主题、关联流程编号、部门、员工编号、姓名、方式、考核结果、岗位确认结果、培训人、确认人和备注。

---

## H-03 考勤、请假与加班资料流程规范

### 适用场景
日常考勤、漏打卡、请假、加班、出差及月度核对。

### 关键步骤
1. 以公司已确认的考勤方式保留原始记录。
2. 异常考勤注明日期、时间、原因和证明资料，不直接覆盖原记录。
3. 请假和加班记录应能对应员工、日期、时段、事由和确认状态。
4. 月度汇总前让员工核对个人记录；争议项单独列出。
5. 修改记录时保留修改前内容、修改原因和确认人。
6. 工资计算方式、加班计算、请假扣款和审批层级均按公司正式制度执行；第一版不自行规定。

### 完成标准
原始记录、异常说明和最终结果能够对应；修改有原因和确认；个人资料不随意公开。

### 异常处理
系统记录与员工说明不一致时，保留两边证据并转【待确认：有权限人员】处理，不先按行政个人判断改数据。

### 使用记录
考勤异常记录、请假记录、加班记录。是否单独制作Excel模板由公司待确认。

## H-04 员工档案流程规范

### 适用场景
入职建档、资料更新、转岗、合同变化和离职归档。

### 关键步骤
1. 每位员工使用唯一员工编号。
2. 建立档案清单，区分已有、缺失、过期和待更新资料。
3. 联系方式、岗位、合同或证件变化时更新，并记录日期。
4. 电子文件按员工编号命名；纸质档案按统一顺序装订。
5. 只有工作需要的人员可以查阅；不得把身份证件、电话等个人信息发到无关群聊。
6. 离职后按法律和公司要求保存或处理，保存期限【待确认】。

### 完成标准
一人一档；资料状态清楚；纸质与电子索引一致；查阅和变更可追溯。

### 异常处理
发现重名混档、员工编号重复或资料错放时，立即暂停使用相关档案，逐项核对身份后更正并记录。

## H-05 文件发布及旧版回收流程规范

### 适用场景
流程规范、图纸、表格、制度和通知首次发布或修订。

### 关键步骤
1. 确认文件编号、名称、关联对象、版本和生效日期。
2. 技术文件由对应业务人员审核，行政负责发放和记录，不替技术部门修改参数。
3. 列出发放位置和使用人员。
4. 新版生效时回收旧版；不能回收的电子文件设置为作废或移出使用入口。
5. 必要时安排变更培训，并关联培训记录。
6. 更新《12文件版本》。旧版保留归档副本，但不能与有效版放在同一使用位置。

### 完成标准
现场只有一个有效入口；版本清单、纸质文件和电子文件一致；旧版已回收或明确作废。

### 异常处理
现场发现无版本文件或新旧版同时使用时，暂停该文件的执行依据，先确认有效版本再恢复。

### 使用记录
《12文件版本》：文件编号、名称、关联对象、类型、版本、生效日期、变更内容、发放位置、旧版处理、确认人、状态和备注。

## H-06 培训记录流程规范

### 适用场景
新员工培训、转岗、流程变更、事故/异常后再培训和年度安排。

### 关键步骤
1. 培训主题要具体，关联到流程编号或文件编号。
2. 记录参加人员，不用“全体员工”代替名单。
3. 只签到不等于完成培训；需要掌握操作的内容应有考核或现场确认。
4. 未通过人员记录补训内容和结果。
5. 流程变更培训要说明“改了什么”，不能只发文件让员工自己看。
6. 结果更新到个人岗位确认或技能记录【具体形式待确认】。

### 完成标准
谁参加、学了什么、依据哪个版本、结果怎样、谁确认都可追溯。

### 使用记录
《13培训记录》。一场培训涉及多人时，可一人一行记录，避免把多人塞进同一单元格后无法统计。

## H-07 劳保及办公用品流程规范

### 适用场景
采购申请、到货、发放、换领和盘点。

### 关键步骤
1. 区分个人领用、部门共用和一次性消耗品。
2. 入库核对名称、规格、数量和状态。
3. 发放记录员工/部门、数量、日期和用途。
4. 换领时记录原因，损坏或异常消耗单独说明。
5. 定期核对库存与记录；盘点频次【待确认】。
6. 与岗位直接相关的防护用品按公司确认标准发放，第一版不编造周期。

### 完成标准
库存、发放和实物基本一致；常用物品不会因无人跟踪突然短缺；异常消耗可查。

### 异常处理
账物不一致时先按实物盘点修正状态，再查未记录领用，不通过补写虚假领用平账。

## H-08 固定资产流程规范

### 适用场景
设备、电脑、空调、量具柜、办公设备等购入、启用、调拨、维修、盘点和报废。

### 关键步骤
1. 建立资产编号并粘贴标识。
2. 记录名称、类别、规格型号、部门、位置、责任人和启用日期。
3. 调拨时同步修改位置和责任人，保留调拨日期。
4. 维修记录关联资产编号。
5. 盘点时核对实物、位置和状态。
6. 报废需有确认依据；审批权限和财务处理【待确认】。

### 完成标准
资产能找到、有人负责、状态准确、维修和调拨可追溯。

### 使用记录
《14固定资产》：资产编号、名称、类别、型号、部门、位置、责任人、启用日期、保养要求、状态、最近盘点日期和备注。

## H-09 会议任务跟踪流程规范

### 适用场景
生产协调、模具异常、客户问题、搬迁或改造等需要多人协作的事项。

### 关键步骤
1. 会议只记录决定、任务和未决问题，不把整段聊天当纪要。
2. 每项任务写清责任人、完成时间、需要的结果或证据。
3. 无法现场决定的事项写“待确认人”和下次确认时间。
4. 到期前更新状态：未开始、进行中、受阻、已完成。
5. “已完成”必须附结果，不以“已经沟通”代替。
6. 涉及流程、图纸或表格变更时，转入文件版本流程。

### 完成标准
每项任务有唯一责任人、有期限、有完成证据；未完成事项不会在下次会议重新从头说起。

### 使用记录
会议任务清单。是否纳入独立Excel工作表【待确认】；第一版可使用会议纪要中的固定表格。

## H-10 离职与工作交接流程规范

### 适用场景
辞职、辞退、合同终止和长期离岗。

### 关键步骤
1. ��认离职日期和交接范围。

7. 交接双方和确认人记录结果，未完成项目列清后续责任人。

### 完成标准
工作不断档；资产已归还或状态明确；公司资料已移交；权限已处理；未完成事项有接手人。

### 异常处理
本人无法完成交接时，由部门和行政共同盘点现有资料与资产，记录缺口，不得事后凭印象补签“全部完成”。

## 2. 编号规则

### 2.1 手册编号

- 第一册产品与文件标准：`A`

## 3. 主数据字段定义

### 3.1 产品

唯一键：`产品编码`

用于区分一个明确的客户版本产品。产品编码不能只表示“0825”，必须能够区分客户和零件。公司已有正式料号时，以正式料号为唯一键。

### 3.2 材料

材料不能只靠“材料牌号”识别。完整材料条件至少包括：

`材料牌号 + 材料厚度(mm) + 材料宽度(mm) + 材料批次`

材料批次属于每次领料记录，不进入产品主数据固定标准。

### 3.3 模具

唯一键：`模具编号`

同一产品如果有多套模具，每套模具分别编号，不使用“1号模”“老模”等无法长期追溯的口头名称作为正式编号。

### 3.4 工位

工位必须和模具一起确认，组合唯一键为：

`模具编号 + 工位号`

推荐使用 `OP10、OP20、OP30……`，中间留号便于以后插入工位。若现有模具有成熟编号，保留现行编号。

### 3.5 模具零件

唯一键：`零件ID`

一个零件ID只对应一种确定设计状态。尺寸或结构发生正式变更时，必须更新图纸版本；是否新建零件ID由公司现行规则决定，第一版标【待确认】。

### 3.6 图纸与文件

- 图纸识别：`图号 + 图纸版本`
- 管理文件识别：`文件编号 + 文件版本`

只写文件名不能保证唯一。现场必须能判断当前有效版本。

### 3.7 人员

人员数据优先使用 `员工编号`。没有员工编号时，行政部分可暂用姓名，但重名后无法唯一识别，因此员工编号规则为【待确认】。

## 5. 表格一致性核对结果

已按以下规则核对：

1. PPT手册的每张标准表，都有唯一的Excel工作表；
2. PPT只解释字段和使用方法，不另建一套不同字段；
3. 厚度、宽度、单位、版本、状态均拆成独立字段；
4. 产品、模具、工位、零件和文件都能通过唯一键追溯；
5. 生产异常能够关联工单、产品、模具和工位；
6. 修机报告能够关联更换零件和试模记录；
7. 所有未经确认的示例数据都带 `EX-` 或“示例”标记。
