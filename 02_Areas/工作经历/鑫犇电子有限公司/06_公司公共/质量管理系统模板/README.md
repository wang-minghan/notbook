# 鑫犇质量与制造管理系统模板

这是用于后续填写和试运行的**模板骨架**，不是现行制度，也不是认证结论。所有空白字段、负责人、权限、频次和判定标准，都必须通过鑫犇真实业务确认后才能生效。

## 设计参考

- [nh-applied-qms](https://github.com/nigelhutch/nh-applied-qms)：文控、不合格、审核、供应商、校准和管理评审模块。
- [Carbon](https://github.com/crbnos/carbon)：制造执行、库存、质量和批次追溯的一体化数据链。
- [ERPNext](https://github.com/frappe/erpnext)：制造、物料消耗、产能、采购、资产和人事等企业流程模块。
- [InvenTree](https://github.com/inventree/InvenTree)：物料、零件、库存和批次追踪的结构化方式。

本模板只借鉴模块划分和数据关系，不复制上述项目代码、品牌或业务规则；实际使用前应分别核对其许可证和部署条件。

`字段与流程映射.md`：各部门工作簿、现有鑫犇表单和后续流程的映射。

## 使用原则

1. 先选一个真实订单、一个产品和一套模具试运行。
2. `待确认` 不等于合格；没有负责人、依据和真实记录，不算完成。
3. 产品必须按“客户 + 产品编码 + 图号/版本 + 材料 + 模具”识别。
4. 模具维修必须关联工位、零件ID、试模记录和恢复结论。
5. 员工身份证、住址、电话等敏感信息不进入本工作簿。
6. `EX-` 开头的内容只能作为填写示例，不得用于生产。

## 第一阶段验收

- 能从一个订单追到材料批次、图纸版本、模具、设备、首件和出货放行记录。
- 任一异常能追到隔离范围、临时措施、根因、纠正措施和验证结果。
- 现场只能使用一个有效版本的图纸和表单。
- 至少完成一次真实订单闭环，而不是只填写模板。
