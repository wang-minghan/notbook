# 多工位级进模设计实用手册｜读书提炼

> 本页只保留可复用的设计框架；原始划线和书籍元数据留在 [[../../../_inbox/科学技术/多工位级进模设计实用手册|Weread 收件箱原文]]，不整篇复制。

## 核心认识

多工位级进模是在单工序冲压模具基础上发展出的多工序集成模具。它把冲裁、弯曲、成形、拉深等工序按送料方向布置在连续工位中，通过条料连续送料完成多道加工。

书中划线还提示：级进模的精度、工位数量和自动化能力较高，但实际适用性取决于压力机、加工材料、零件工艺特征、送料与检测条件，不能只因“级进模”名称而直接套用结构。

## 可复用设计流程

1. **明确设计任务书**：确认产品、材料、产量、设备、质量要求和交付资料。
2. **工艺分析**：识别冲裁、弯曲、成形、拉深等工序及其先后关系。
3. **工艺计算**：计算必要的冲压力、成形条件、送料步距等参数。
4. **排样设计**：确定条料利用、工位排列、载体与送料方案，并绘制排样图。
5. **总装图设计**：围绕工作顺序配置上模、下模、卸料、导向和支承结构。
6. **零件图与资料归档**：完成零件图、出图、明细栏、使用说明及全套资料存档。

## 结构要点

- **卸料板**同时承担卸料、压料和导向作用；合模时先压紧条料，减少移动、走料和扭曲。
- **上模座、固定板垫板、固定板**分别承担模具上部固定、承力和凸模夹持定位等功能。
- **下模板、下模板垫板、下模座**分别承担凹模镶件固定、承力和下模部分固定等功能。
- 模架层级应服务于受力、导向、维护和加工要求；不能仅按书中示意层数机械复制到每一套产品模具。

## 与鑫犇模具项目的连接

- 本书可作为级进模设计的通用参考框架，辅助检查“产品 → 材料 → 工序 → 模具 → 工位 → 装配/试模 → 首件确认”链路是否完整。
- 它不能替代具体产品的图纸、材料牌号与料厚、设备能力、排样计算、模具专属孔位和试模记录。
- 鑫犇项目仍按“共用模具结构标准 + 每套模具独立型号与专属参数”管理；本页的流程和结构知识不能直接生成某套模具的生产参数。
