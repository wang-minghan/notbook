# 材料主数据

## 1. 定位

本文件是材料实体的主数据入口，通过材料编码与中心实体《产品主数据.md》关联。供应商、材料批次、库存和领料属于业务记录或关联实体，不并入材料主编码。

## 2. 主键规则

- **材料编码：主键，必须唯一且稳定。**
- 推荐结构：`材料牌号-厚度-宽度`。
- 供应商不纳入材料编码。
- 供应商批次单独记录在材料批次或来料记录中。
- 厚度、宽度或材料牌号未确认时填写“待补”，不得猜填正式编码。

## 3. 字段定义

| 字段 | 是否主键 | 填写规则 | 状态 |
|---|---:|---|---|
| 材料编码 | 是 | 材料牌号-厚度-宽度 | 已确认规则 |
| 材料牌号 | 否 | 以批准图纸/BOM或来料资料为准 | 必填方向已确认 |
| 厚度 | 否 | 保留原始单位和精度，待资料确认 | 业务值待补 |
| 宽度 | 否 | 保留原始单位和精度，待资料确认 | 业务值待补 |
| 材料名称 | 否 | 人员易识别名称 | 推荐字段 |
| 材料状态 | 否 | 待确认、有效、停用等 | 状态值待确认 |
| 供应商编码 | 否 | 不纳入材料主键；在供应关系/来料记录维护 | 关联待确认 |
| 规格来源 | 否 | 图纸、BOM、采购/来料资料等 | 推荐字段 |
| 备注 | 否 | 记录材料易混、校对说明等 | 推荐字段 |

## 4. 与产品的关系

```text
产品编码 → 产品材料关联 → 材料编码
材料编码 → 材料批次编码 → 库存/领料/工单记录
```

一个产品可使用一种或多种材料；一项材料也可能用于多个产品。正式系统化时可使用产品材料关联表表达用量、有效期或适用状态，当前不要求立即新建表。

## 6. 质量检查

- 材料编码不得把供应商或供应商批次混入主编码。
- 同一牌号但厚度或宽度不同，应形成不同材料编码。
- 产品主数据中的材料编码必须能在本文件找到。
- 采购来料的批次、检验和库存状态不得用材料主数据的静态属性替代。
- 任何具体规格必须由批准图纸、BOM或受控来料资料核对。
