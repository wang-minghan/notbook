## 1. 产品图纸：10型下机壳

### 1.1 图纸基本信息
- 零件名称：**下机壳**
- 型号：**10型下机壳**
- 材质：**SPCC-SD**
- 比例：**1:1**
- 公司：**鑫萍电子有限公司**（照片识别结果）

### 1.2 图纸重点
- 图纸上带 **★** 的尺寸是重点监控尺寸。
- 有明确的技术要求、盐雾测试条件、表面处理要求和装配/焊接要求。
- 这是典型的制造/检验用图纸，不只是看外形，要同时看尺寸、公差和工艺要求。

### 1.3 可见的关键要求
- 外观不能有明显缺陷，毛刺需控制。
- 未注公差按图纸规定等级执行。
- 表面处理包含镀镍等要求。
- 盐雾测试后不能生锈。
- 部分尺寸为关键控制项，需要重点复核。

### 1.4 尺寸/特征要点
以下为照片中较清晰的识别结果，建议后续复核原图：
- 圆形主体带两侧/上下突起结构
- 角度特征：**120°**
- 关键尺寸：**φ10 ±0.05、φ8.6 +0.05/-0.01、φ9.6 +0.05/0**
- 局部深度：**深0.08 Min**
- 其余可见尺寸包括：**0.8 ±0.03、0.3 ±0.03、1.1 ±0.05、0.2 ±0.03、R0.2MAX、R0.14MAX** 等

## 3. 材料型号容易混淆

### 3.1 机壳 / 磁栅 / 转子片 / 垫片类
- **立得磁（无刷）机壳**：涉及 0515、0518、0525、0620、0625、0825、1027、1234 等型号，材料包括 **SPCC、C2800、SUS430、SUS304** 等不同厚度规格。
- **DC0625（无刷）机壳**：上机壳、下机壳等材料有 **SUS430、C2800、SPCC** 等。
- **立得磁（无刷）磁栅**：常见材料为 **SPCC-0.25X15 / 0.20X15 / 0.23X15**。
- **立得磁（线性）磁栅**：常见材料为 **SUS430-0.15X11、SPCC-0.20X10**。
- **0825 / 0832 系列上、下机壳**：不同客户版本对应的材料差异很大，容易混料。
- **极片 / 垫片 / 隔板**：常见材料包括 **SUS304、SUS301、SPCC**。
- **制动片**：材料多为 **拔簧白金 0.05X10 / 0.05X13**，硬料/软料要分清。

### 3.2 容易混淆的点
- 同一个型号，客户不同，材料不同。
- 同一个客户，不同结构件（上机壳 / 下机壳 / 磁扣 / 制动片 / 盖板）也会用不同材料。
- **型号、客户、材料规格**三者必须一起看，不能只看一个字段。

## 4. 今天能直接用的结论

1. 这家公司的产品信息主要围绕 **机壳、磁扣、磁栅、制动片、隔板、极片、垫片** 这些零件展开。  
2. 图纸和重量表都说明：**同型号不同客户版本差异非常大**，材料和单重不能乱套。  
3. 质量审查时，必须同时确认：**图纸版本、关键尺寸、材料规格、表面处理、单重**。  
4. 以后最实用的做法不是死记，是把这些资料做成 **“型号-客户-材料-单重-图纸”** 的对照库。
