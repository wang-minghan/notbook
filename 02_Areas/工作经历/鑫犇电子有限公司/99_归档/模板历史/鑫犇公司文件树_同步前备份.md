# 鑫犇电子有限公司文件树

> 当前组织架构已确认。组织单元、岗位和职责矩阵以《鑫犇电子_公司组织架构与职责矩阵模板.xlsx》为唯一受控来源；未完成事项仅在该文件的“05_确认清单”中跟踪。

## 现行组织架构

> 公司是最高层级；董事长与总经理同属公司层级，不能表达为“董事长 → 总经理”的上下级关系。

```text
公司
├── 董事长
└── 总经理
    ├── 生产部
    │   ├── 工程技术组
    │   ├── 清洗车间
    │   ├── 生产车间
    │   └── 模具维修组
    ├── 品质部
    │   ├── 制程巡检组
    │   └── 成品出货检验组
    ├── 运营部
    │   ├── 业务组
    │   ├── 采购组
    │   └── 仓储组
    ├── 行政部
    │   ├── 人事组
    │   └── 后勤组
    └── 财务部
        ├── 会计组
        └── 出纳组
```

> 可视化架构图：见 Excel 工作表“01_组织架构图”。结构化维护数据：见“02_组织单元”。岗位名称可按实际工作自定义，但岗位所属组织单元及层级必须引用上述正式架构。

## 资料归属规则

| 组织单元 | 主要资料 |
|---|---|
| 生产部 | 产品资料、产品主数据、材料型号、图纸和技术标准 |
| 生产部/生产车间 | 生产任务、生产记录、首件、巡检、批次和现场异常 |
| 生产部/模具车间 | 模具资料、修模、试模、模具履历和维修记录 |
| 品质部/质检班组 | 来料、首件、制程和最终检验；质量异常、不合格品、客诉、审核和质量指标 |
| 运营部/业务 | 客户、订单、客户要求、拜访纪要和交付协调 |
| 运营部/采购 | 供应商、采购、来料和外协协调 |
| 运营部/仓管 | 材料、成品、库存、批次和出入库记录 |
| 行政部/人事 | 员工档案、入职、考勤、培训和岗位能力 |
| 行政部/后勤 | 后勤、办公用品、固定资产和综合保障 |
| 财务部/会计 | 账务、核算、报表和财务资料 |
| 财务部/出纳 | 收付款、现金、银行和资金记录 |
| 公司公共 | 跨部门制度、组织架构、通用模板、会议和管理评审 |

## 使用规则

- 公司主入口只保留一份：[[鑫犇电子有限公司]]。
- 组织架构、组织单元和岗位以《鑫犇电子_公司组织架构与职责矩阵模板.xlsx》为唯一受控来源。
- 公司治理不保存员工姓名、工种、电话等人员明细；人员底表和原始花名册统一位于 `04_行政部/人事/`。
- 岗位名称可根据实际工作自定义；岗位所属组织单元必须使用正式组织架构中的名称。品质部组织单元统一为“制程巡检组”和“成品出货检验组”。
- “营运部”统一为正式名称“运营部”。
- 跨部门表单、会议纪要和管理评审统一进入 `06_公司公共`。
- 废止版本和历史资料进入 `99_归档`，不从当前执行入口引用。
- `06_公司公共/质量管理系统模板/`：质量与制造管理系统模板，作为真实订单试运行入口。
