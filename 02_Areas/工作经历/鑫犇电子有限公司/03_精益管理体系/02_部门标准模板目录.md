# 鑫犇电子有限公司｜部门标准模板目录

## 0. 文件定位与边界

本文件是各部门“标准化模板包”的目录、字段规范和责任边界，不替代正式组织架构。组织单元、层级和岗位归属以《鑫犇电子_公司组织架构与职责矩阵模板.xlsx》为唯一受控来源。

- **正式标准**：当前已从公司文件树或现有模板确认的组织、资料归属、字段和编号规则。
- **参考说明**：为模板包设计提供的管理建议；未获得公司批准前，不作为生产、检验、采购、薪酬或财务执行标准。
- **待确认**：尚缺正式负责人、审批权限、参数、频次、阈值、编号规则或是否实际开展的事项。
- **模板状态**：本目录设计的是模板包结构；模板投入正式使用前，须由责任部门确认字段、权限、版本和表单编号。

> 现有事实：公司现行组织包含生产部（工程技术组、清洗车间、生产车间、模具维修组）、品质部（制程巡检组、成品出货检验组）、运营部（业务组、采购组、仓储组）、行政部（人事组、后勤组）和财务部（会计组、出纳组）。因此财务部并非“组织不存在”，但具体财务流程和模板责任人仍需确认。

## 2. 跨部门统一记录规则

每个流程模板均按以下七段说明配套使用：

1. **适用场景**：何时启动、适用组织单元和产品/订单范围。
2. **开始前确认**：资料、权限、版本、物料、设备/模具和前置记录。
3. **关键步骤**：按顺序填写或执行；每一步有责任人。
4. **完成标准**：记录完整、结果明确、必要确认完成、状态可关闭。
5. **异常处理**：停用/隔离/返工/补料/升级/批准和恢复条件。
6. **使用记录**：指定模板名称、记录编号、保存位置、保管责任和保存期限。
7. **原理与作用**：只说明能防止误用、混料、错版或漏检的必要原理。

所有表单必须有：记录编号、日期/时间、责任人、状态、确认/批准（适用时）、备注。涉及产品、材料、图纸、模具、工单或批次的表单，必须引用统一主数据字段，不得只填简称。

## 3. 部门模板包规范

### 3.1 运营部/业务组（正式组织）

- **部门定位**：承接客户、产品/交付需求和订单接口，组织订单评审与跨部门交付协调；不替代工程、品质对技术和质量结论的审批。
- **输入**：客户信息、客户要求、产品/型号、数量、交期、质量/包装/标签要求、图号+版本、材料要求；现有“客户订单评审”模板已包含其中多项字段。
- **输出**：订单评审结论、交付协调记录、客户拜访纪要、客户需求变更、客诉接口及关闭证据。
- **核心标准模板**：客户主数据；客户需求/订单评审；订单交付跟踪；客户拜访纪要；客户投诉与回复接口；客户要求变更记录。
- **关键指标**：订单评审及时率、按期交付率、客户要求一次识别率、客户投诉按期关闭率、需求变更漏传率。目标值和统计口径**待确认**。
- **异常升级**：客户要求不清或冲突→总经理/业务负责人；交期风险→运营部与生产部；技术/质量风险→工程技术组和品质部；重大客户投诉→总经理、品质部。升级时不得自行修改技术标准。
- **记录字段**：订单号、日期、客户、产品编码、图号、图纸版本、数量、交期、材料牌号、材料厚度、材料宽度、材料批次、模具编号、设备编号、质量/包装/标签要求、评审结论、风险与措施、评审人、批准人、状态、备注。

### 3.2 生产部/工程技术组（正式组织）

- **部门定位**：维护产品、图纸、工艺和技术变更接口，为生产、模具和品质提供受控技术依据。
- **输入**：客户需求/订单评审、产品信息、图纸、材料规格、现行工艺、试模/试产反馈、质量异常。
- **输出**：产品与工艺主数据、受控图纸及版本、工艺文件、试模/试产结论、工程变更通知、技术异常处理意见。
- **核心标准模板**：产品主数据；材料/客户/型号对照；图纸与文件版本清单；工艺路线/参数记录；工程变更申请与验证；试模/试产记录。
- **关键指标**：图纸/工艺版本准确率、工程变更按期关闭率、试模一次通过率、技术问题重复发生率。阈值和统计周期**待确认**。
- **异常升级**：图纸缺失/版本冲突→工程负责人和总经理；材料与产品/客户不匹配→采购、仓储、品质和业务共同确认；试模不通过→模具维修组、生产、品质；影响交付的变更→业务/运营部。
- **记录字段**：产品编码、产品名称、客户、产品型号、材料牌号、材料厚度、材料宽度、图号、图纸版本、文件编号、文件版本、工艺步骤、关键特性、模具编号、工位号、设备编号、变更原因、变更内容、验证结果、责任人、批准人、生效日期、状态、备注。

> 已知事实边界：产品资料显示同型号不同客户版本的材料和单重可能不同；图纸完整版本号、正式BOM/材料号、部分关键尺寸和模糊单重仍待原件复核，不得由本目录固化为正式参数。

### 3.3 生产部/清洗车间、生产车间（正式组织）

- **部门定位**：按受控订单、图纸、工艺和生产任务制造并记录批次、数量、首件、过程和交接结果。
- **输入**：生产任务/工单、产品编码、图号+版本、材料与批次、模具/工位、设备、检验要求、包装/标签要求。
- **输出**：生产日报/批次记录、领料与退料记录、首件送检、过程记录、合格品/不合格品数量、异常与交接班记录。
- **核心标准模板**：生产任务确认；物料领用/退料；首件制作与送检；过程生产记录；清洗批次记录；产量与工时记录；生产异常；交接班记录。
- **关键指标**：计划达成率、一次合格率、材料损耗率、设备/模具停机时间、批次追溯完整率、异常关闭及时率。目标和公式**待确认**。
- **异常升级**：错料、错版、模具/设备异常、关键尺寸异常、批次混淆→立即停机/隔离并通知品质、工程/模具维修；交期风险→生产负责人和运营部；人员/安全风险→行政部/后勤和总经理。
- **记录字段**：记录编号、日期、班次、工单号、产品编码、图号、图纸版本、材料牌号、材料厚度、材料宽度、材料批次、模具编号、工位号、设备编号、计划数量、投入数量、合格数量、不合格数量、报废数量、生产开始时间、生产结束时间、操作人、首件结果、异常编号、交接人、确认人、状态、备注。

### 3.4 品质部/制程巡检组、成品出货检验组（正式组织）

- **部门定位**：执行来料/制程/成品/出货检验，管理不合格隔离、质量异常、放行和改善验证；品质结论不由生产自行替代。
- **输入**：受控图纸/版本、检验标准、订单和客户要求、样品/批次、生产记录、材料信息、检具/设备状态。
- **输出**：首件检查、过程巡检、来料/成品/出货检验、放行或不合格判定、异常隔离与处理、质量月报、改善/审核记录、客诉质量结论。
- **核心标准模板**：首件检查；过程巡检；来料/外协检验；成品检验与出货放行；不合格与异常；质量目标与月报；改善与审核；客诉质量分析。
- **关键指标**：来料合格率、首件一次通过率、过程不良率、成品合格率、出货投诉率、异常按期关闭率、检验记录完整率。目标值、抽样方案和判定阈值**待确认**。
- **异常升级**：关键尺寸/功能不合格、错料/错版、批量异常、客户投诉、放行争议→品质负责人和总经理；涉及图纸/工艺→工程技术组；涉及供应商→采购；影响交付→业务组。
- **记录字段**：记录编号、日期、发现日期时间、工单号、订单号、产品编码、图号、图纸版本、材料牌号、材料批次、模具编号、工位号、检查项目、图纸标准、实测值、单位、检具、累计数量、结果、外观结果、异常编号、异常情况、隔离范围、临时处理、处理结果、检查人、确认人、关闭日期、状态、备注。

> 现有《质量管理与检验模板.xlsx》中的“客户订单评审、质量目标与月报、改善与审核、首件检查、过程巡检、不合格与异常”字段作为已存在模板事实保留。后续改版只能经字段映射确认，不能悄然改名。

### 3.5 运营部/采购组（正式组织）

- **部门定位**：依据批准需求采购材料、外协和相关物资，维护供应商接口、交期和来料异常协调；不替代品质对来料合格性的判定。
- **输入**：采购申请/订单需求、产品和材料主数据、供应商信息、交期、质量要求、库存/安全库存信息。
- **输出**：供应商主数据与评估、采购订单/跟催、到料信息、供应商异常与改善跟踪、采购台账。
- **核心标准模板**：供应商主数据；供应商准入/评估；采购申请；采购订单与交期跟踪；材料批次到料登记；供应商质量/交期异常；对账接口。
- **关键指标**：按期到料率、采购批次追溯完整率、供应商来料合格率、采购异常关闭及时率、紧急采购比例。阈值**待确认**。
- **异常升级**：交期延误→运营负责人、生产和业务；材料牌号/厚度/宽度不符→仓储先隔离，品质判定，工程确认；供应商重大质量/重复异常→总经理。
- **记录字段**：采购申请编号、采购订单号、日期、供应商、供应商编号、产品编码、材料编码、材料牌号、材料厚度、材料宽度、材料批次、数量、单位、要求到货日期、实际到货日期、质量要求、检验状态、异常编号、责任人、处理措施、关闭日期、状态、备注。

### 3.6 运营部/仓储组（正式组织）

- **部门定位**：管理材料、在制品、成品的收发存、批次、库位和盘点，保证账物卡/系统记录可追溯；仓储不替代品质放行。
- **输入**：采购到料、检验结论、生产领退料、成品入库、出货指令、盘点任务。
- **输出**：收货/入库、领料/退料、成品入库/出库、库存台账、批次追溯、盘点差异、呆滞/隔离清单。
- **核心标准模板**：物料/成品主数据；收货与入库；领料与退料；成品入库/出货；库存批次台账；盘点差异；隔离品/呆滞料清单。
- **关键指标**：库存账实相符率、批次追溯完整率、收发准确率、盘点差异关闭率、呆滞料识别及时率。盘点频次和阈值**待确认**。
- **异常升级**：无检验状态/无批次/标签不清→隔离并通知品质、采购；账实不符→仓储负责人和财务；出货数量/版本不符→业务、品质和生产；危险或损坏→后勤/总经理。
- **记录字段**：库存记录编号、日期、业务类型、单据号、产品编码、产品名称、材料编码、材料牌号、材料厚度、材料宽度、材料批次、数量、单位、库位、入库日期、出库日期、检验状态、隔离状态、经手人、复核人、盘点日期、账面数量、实盘数量、差异数量、处理结果、状态、备注。

### 3.7 生产部/模具维修组；设备管理范围待确认

- **部门定位**：模具维修组负责模具、零件、维修、试模和履历；正式组织中未单列“设备部/设备组”，设备管理责任、设备台账和点检归属**待确认**，不得把设备管理默认为模具维修组职责。
- **输入**：模具编号/工位、图纸和零件图、维修申请、试模问题、生产/品质异常、备件需求。
- **输出**：模具/零件台账、点检/维修履历、换件记录、试模记录、维修验证、备件需求和停机信息。
- **核心标准模板**：模具主数据与零件台账；模具点检；维修申请/修机报告；模具维修履历；试模与验证；备件库存；设备资产/点检模板（责任部门待确认）。
- **关键指标**：模具可用率、维修按期完成率、重复故障率、试模一次通过率、维修后验证完整率；设备点检及时率和停机率的责任归属**待确认**。
- **异常升级**：模具影响尺寸/批量质量→品质与工程；维修预计影响交期→生产、业务；关键备件缺料→采购；设备故障/安全风险→设备责任部门（待确认）、后勤和总经理。
- **记录字段**：维修/点检记录编号、日期、模具编号、模具名称、工位号、零件ID、图号、图纸版本、设备编号、故障现象、发现数量/批次、原因分析、维修措施、更换零件、开始时间、完成时间、试模结果、验证人、确认人、停机时间、状态、备注。

### 3.8 行政部/人事组、后勤组（正式组织）

- **部门定位**：人事组维护人员主数据、入离职、考勤、培训和岗位能力；后勤组负责固定资产、办公/后勤保障和综合服务。行政部不替代各专业部门确认岗位技术能力。
- **输入**：组织架构和岗位、员工资料、入离职信息、考勤、培训需求、资产采购/领用/维修需求、后勤事项。
- **输出**：员工主数据、入离职记录、考勤、培训记录、岗位能力矩阵、固定资产台账、办公用品和后勤服务记录。
- **核心标准模板**：员工主数据；入职/转岗/离职；考勤与请假；培训计划/签到/评价；岗位能力矩阵；固定资产；办公用品；后勤维修/安全隐患。
- **关键指标**：人员主数据完整率、培训完成率、关键岗位能力覆盖率、考勤异常关闭率、资产账实相符率、后勤事项按期完成率。薪酬、劳动纪律和安全制度细则**待确认**。
- **异常升级**：关键岗位无能力确认→部门负责人和行政；人员短缺影响交付→总经理、生产/运营；资产盘亏/损坏→后勤、行政和财务；工伤/重大安全隐患→立即采取保护措施并升级总经理。涉及个人敏感信息须限权保存。
- **记录字段**：员工编号、姓名、所属组织单元、岗位名称、入职日期、转岗日期、离职日期、培训编号、培训主题、培训日期、培训对象、讲师、考核结果、能力项目、能力状态、确认人、资产编号、资产名称、规格、使用部门、保管人、领用日期、归还日期、维修状态、记录人、状态、备注。

### 3.9 财务部/会计组、出纳组（正式组织；具体模板边界待确认）

- **部门定位**：组织架构已列财务部、会计组和出纳组。会计组负责账务、核算、报表和财务资料；出纳组负责收付款、现金、银行和资金记录。具体核算制度、审批链、税务口径和系统尚未在现有资料中确认。
- **输入**：采购/销售/仓储单据、合同/订单、收付款申请、发票、费用报销、工资及资产资料。
- **输出**：会计凭证、应收应付、成本/费用核算、财务报表、收付款登记、现金/银行记录、对账和财务档案。
- **核心标准模板**：会计凭证与附件清单；应收账款；应付账款；采购/销售对账；费用报销；成本归集接口；收付款申请；现金/银行日记账；资金日报；资产折旧接口。具体表式和审批权限**待确认**。
- **关键指标**：凭证及时完整率、应收/应付对账完成率、收付款准确率、资金日报及时率、库存/采购/销售账务接口差异关闭率。目标、公式和截止日**待确认**。
- **异常升级**：单据缺失/金额不一致→会计负责人和业务部门；付款权限或资金风险→财务负责人、总经理；库存账实差异→仓储、财务；重大税务/现金/银行异常→总经理。
- **记录字段**：财务记录编号、业务单据号、日期、业务类型、客户/供应商、产品编码、材料批次、数量、金额、不含税金额、税额、含税金额、付款/收款方式、银行/现金账户、发票编号、会计科目、成本中心、经办人、复核人、批准人、对账日期、状态、附件位置、备注。

## 4. 通用模板字段字典

### 4.1 主键与关联键（必须优先使用）

| 字段名 | 定义与使用规则 |
|---|---|
| 记录编号 | 每条表单记录的唯一编号；不得用“今天/临时”替代。编号规则待确认。 |
| 订单号 | 客户订单或内部订单的唯一标识。 |
| 工单号 | 生产任务的唯一标识；没有工单不得自行编造。 |
| 产品编码 | 产品/零件的正式编码；**必须作为产品主键**，不得只填产品简称或型号。 |
| 产品名称 | 产品/零件名称，作为可读名称，不替代产品编码。 |
| 客户 | 客户正式名称；同型号不同客户版本必须分开识别。 |
| 产品型号 | 客户或公司使用的型号；与产品编码分开。 |
| 材料编码 | 材料主数据编码；若未建立，填写状态为“待确认”，不得以猜测编码代替。 |
| 材料牌号 | 如SPCC-SD、SUS430等正式材料牌号。 |
| 材料厚度 | 材料厚度，保留数值和单位；不得与材料牌号合并成不可拆字段。 |
| 材料宽度 | 材料宽度，保留数值和单位。 |
| 材料批次 | 供应商/来料批次，用于追溯；不能用采购订单号替代。 |
| 模具编号 | 模具的正式唯一标识；**必须作为模具主键**。 |
| 工位号 | 模具内或工艺路线中的工位标识；涉及工位时必须与模具编号同时填写。 |
| 零件ID | 模具/设备组成零件的唯一标识；维修履历必须引用。 |
| 设备编号 | 设备资产的唯一标识；设备组织归属尚待确认。 |
| 图号 | 工程图纸的正式编号。 |
| 图纸版本 | 图号对应的受控版本；**图号+图纸版本**共同识别一份图纸。 |
| 文件编号 | 管理文件、流程规范或表单的正式编号。 |
| 文件版本 | 文件编号对应的受控版本；**文件编号+文件版本**共同识别一份文件。 |

### 4.2 业务、结果与责任字段

| 字段名 | 定义与使用规则 |
|---|---|
| 日期 | 业务发生日期。 |
| 发现日期时间 | 异常/缺陷首次发现的日期和时间。 |
| 生产开始时间 | 本批/本工单实际开始时间。 |
| 生产结束时间 | 本批/本工单实际结束时间。 |
| 数量 | 数量必须同时填写单位；按业务语义区分计划、投入、合格、不合格等。 |
| 单位 | 件、卷、公斤等计量单位；不能省略。 |
| 检查项目 | 检验或确认的具体项目。 |
| 图纸标准 | 检查依据中的标准值/公差/要求；不得只写“合格”。 |
| 实测值 | 实际测量结果；应与单位、检具对应。 |
| 单位 | 实测值的计量单位；同一记录只表示一个明确单位。 |
| 结果 | 合格、不合格、待判定等状态值，统一使用受控词。 |
| 异常编号 | 关联异常处理记录的唯一编号。 |
| 异常类别 | 质量、材料、交期、设备、模具、文件、人员、库存、财务等受控分类。 |
| 异常现象 | 可观察事实，不写未经验证的原因。 |
| 隔离范围 | 被隔离的批次、数量、库位、工单或成品范围。 |
| 原因分析 | 经确认的原因或分析过程；初步猜测需标“待确认”。 |
| 临时处理 | 防止继续扩大影响的临时措施。 |
| 处理措施 | 经批准的长期纠正/改善措施。 |
| 恢复条件 | 允许恢复生产、入库、出货或付款的明确条件。 |
| 处理结果 | 措施执行后的结果。 |
| 责任人 | 对该动作或记录负责的人员；人员主数据优先引用员工编号。 |
| 员工编号 | 人员主数据唯一标识；正式字段名称建议固定为“员工编号”，若现有表单使用其他名称须做映射后统一。 |
| 检查人 | 实施检验的人。 |
| 记录人 | 填写记录的人。 |
| 确认人 | 对记录或结果进行确认的人。 |
| 评审人 | 订单、变更或风险评审执行人。 |
| 批准人 | 需要管理批准时的批准人。 |
| 状态 | 建议受控值：草稿、待确认、进行中、待判定、合格、不合格、已隔离、待批准、已关闭、作废。最终值表待确认。 |
| 关闭日期 | 异常、改善、任务或对账完成并被确认关闭的日期。 |
| 备注 | 补充说明；不能用来替代必填字段。 |
| 附件位置 | 图纸、照片、报告、发票或证据的受控存放路径/链接。 |

### 4.3 版本、状态和填写规则

1. “型号、客户、材料规格”必须一起判断，不能单凭型号领料、生产或放行。
2. “图号+图纸版本”用于工程/生产/品质技术依赖；“文件编号+文件版本”用于管理文件和模板。两组字段不可混用。
3. “模具编号+工位号”用于定位模具工位；“零件ID”用于定位模具/设备组成件。
4. 产品、材料、模具、图纸、文件和人员均应先建主数据再在业务表单中引用；主数据缺失时标记“待确认”，不能编造。
5. 任何示例行必须使用`EX-`前缀并标注“虚拟示例，不可用于生产/加工/检验”。
6. 记录修改保留原记录编号、修改人、修改日期和修改原因；不得覆盖造成不可追溯。
7. 表单字段名以本字典为准；若既有模板存在不同字段名，先建立“旧字段→标准字段”的映射表，再改版并保留历史版本。

## 5. 正式标准、参考说明、待确认清单

### 5.1 正式标准/已确认事实

- 组织架构以《鑫犇电子_公司组织架构与职责矩阵模板.xlsx》为唯一受控来源。
- 现有部门与组织单元边界如本文件第0节所列。
- 品质部正式组织单元为制程巡检组和成品出货检验组。
- 资料归属：产品/材料/图纸/技术标准归生产部；生产记录归生产车间；模具资料归模具维修组；品质记录归品质部；客户/订单归业务；供应商/采购归采购；库存/批次归仓储；人员归人事；后勤/资产归后勤；账务和资金归财务。
- 现有品质模板包含客户订单评审、质量目标与月报、改善与审核、首件检查、过程巡检、不合格与异常等表单字段，应作为既有事实保留。
- 产品资料表明同型号不同客户版本可能存在材料、结构和单重差异；生产和检验必须同时核对客户、型号/产品编码、材料规格和图纸版本。

### 5.2 参考说明（未批准前不可当执行参数）

- 可将模板包按“主数据—业务记录—异常/改善—指标报表”分层，以减少重复录入。
- 指标应统一定义分子、分母、统计周期、责任人和数据来源后再发布目标值。
- 质量、仓储、采购和财务之间应通过订单号、工单号、产品编码、材料批次和单据号关联，而不是依赖自由文本。

### 5.3 待确认事项

- 各模板的正式文件编号、版本、批准人、生效日期和保存期限。
- 各部门模板实际负责人、复核人、批准权限和替代岗。
- 产品正式编码、材料编码、BOM、完整图纸版本、关键尺寸最终值和单重模糊数据。
- 设备管理是否设为独立组织单元，或由生产部/后勤组/模具维修组承担；设备编号、点检和维修权限。
- 采购审批额度、供应商准入规则、来料抽样/放行标准和交期阈值。
- 品质抽样方案、关键特性判定、放行权限、客户投诉等级和异常关闭时限。
- 仓储库位规则、盘点频次、先进先出/批次规则和呆滞料定义。
- 人事考勤、培训合格线、岗位授权、薪酬及劳动纪律细则。
- 财务科目、税务、报销、付款审批、资金限额、成本核算和财务档案保存规则。
