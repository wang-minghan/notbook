# 统一字段、编号、术语与表格映射

## 1. 统一术语

| 不再使用或避免混用 | 统一写法 | 说明 |
|---|---|---|
| SOP、作业SOP | 流程规范 | 全手册统一 |
| 品名、产品名、零件品名 | 产品名称 | 指交付或生产对象 |
| 料号、产品编号、自编号 | 产品编码 | 公司已有正式料号时直接沿用 |
| 模号、模具号 | 模具编号 | 一套模具一个编号 |
| 工序号、工步号、站号 | 工位号 | 级进模统一用 OP10、OP20……；现行编号优先 |
| 配件编号、镶件编号 | 零件ID | 模具零件唯一编号 |
| 材质 | 材料牌号 | 如 SPCC、SUS430、C2800 |
| 料厚 | 材料厚度(mm) | 不与料宽写在同一格 |
| 料宽 | 材料宽度(mm) | 不与材料牌号写在同一格 |
| 版本、版次 | 图纸版本 / 文件版本 | 根据对象区分 |
| OK、NG、不确定 | 合格 / 不合格 / 待判 | 记录用中文状态 |
| 修模单、修机单 | 修机报告 | 与配套表格一致 |
| 库存数、备件数 | 当前库存 / 备品数量 | 库存动态数与设计备品数分开 |
| 操作员、员工 | 记录人 / 检查人 / 维修人 / 确认人 | 按实际动作命名，不用含糊的“负责人” |

## 2. 编号规则

### 2.1 编号前缀（不代表册次或独立部门）

- 共用产品与文件标准：`A`
- 生产部流程规范：`P`
- 生产部—模具维修组专项内容：`M`（模具维修组是生产部下属班组）
- 行政部/人事流程规范：`H`

品质部、营运部和财务部的流程编号待现有流程及编号需要确认后再决定，不在此处臆造编号。以上字母仅为文件/表单编号前缀，不代表本手册册次。

流程规范编号：`前缀-两位章节-两位流程`

示例：
- `P-01-01`：生产任务确认流程规范
- `M-06-01`：试模流程规范
- `H-05-01`：文件发布及旧版回收流程规范

### 2.2 表单编号

格式：`FR-部门字母-两位序号`

| 表单编号 | 表单名称 |
|---|---|
| FR-A-01 | 产品主数据 |
| FR-A-02 | 易混材料对照 |
| FR-P-01 | 生产任务确认单 |
| FR-P-02 | 领料核对记录 |
| FR-P-03 | 首件检查记录 |
| FR-P-04 | 生产巡检记录 |
| FR-P-05 | 异常处理记录 |
| FR-M-01 | 模具零件及镶件台账 |
| FR-M-02 | 试模记录 |
| FR-M-03 | 修机报告 |
| FR-M-04 | 模具备品库存 |
| FR-H-01 | 文件版本清单 |
| FR-H-02 | 培训记录 |
| FR-H-03 | 固定资产台账 |

表单编号用于手册引用，不强制替代公司已经在使用的文件编号。

### 2.3 业务记录编号

若公司没有现行规则，当前仅列为建议：

- 异常编号：`YC-年月日-三位流水号`
- 试模编号：`SM-年月日-三位流水号`
- 修机报告编号：`XJ-年月日-三位流水号`
- 培训编号：`PX-年月日-三位流水号`

以上属于【待确认】。已有编号体系时，直接沿用，不建立双轨编号。

## 3. 主数据字段定义

### 3.1 产品

唯一键：`产品编码`

用于区分一个明确的客户版本产品。产品编码不能只表示“0825”，必须能够区分客户和零件。公司已有正式料号时，以正式料号为唯一键。

### 3.2 材料

材料不能只靠“材料牌号”识别。完整材料条件至少包括：

`材料牌号 + 材料厚度(mm) + 材料宽度(mm) + 材料批次`

材料批次属于每次领料记录，不进入产品主数据固定标准。

### 3.3 模具

唯一键：`模具编号`

同一产品如果有多套模具，每套模具分别编号，不使用“1号模”“老模”等无法长期追溯的口头名称作为正式编号。现行已确认格式为“公司缩写 + 产品型号 + 模具套别字母”，例如 `ldw1027b`；末尾字母只表示同型号下的模具套别，不表示图纸/CAD版本。图纸版本必须单独记录，图纸变更不改变模具编号。

### 3.4 工位

工位必须和模具一起确认，组合唯一键为：

`模具编号 + 工位号`

推荐使用 `OP10、OP20、OP30……`，中间留号便于以后插入工位。若现有模具有成熟编号，保留现行编号。

### 3.5 模具零件

唯一键：`零件ID`

一个零件ID只对应一种确定设计状态。尺寸或结构发生正式变更时，必须更新图纸版本；是否新建零件ID由公司现行规则决定，第一版标【待确认】。

### 3.6 图纸与文件

- 图纸识别：`图号 + 图纸版本`
- 管理文件识别：`文件编号 + 文件版本`

只写文件名不能保证唯一。现场必须能判断当前有效版本。

### 3.7 人员

人员数据优先使用 `员工编号`。没有员工编号时，行政部分可暂用姓名，但重名后无法唯一识别，因此员工编号规则为【待确认】。

## 5. 表格一致性核对原则（现有PPT/工作簿尚未实证）

正式同步时应按以下规则核对；本文件目前未完成逐个工作簿、工作表和PPT页的实证比对：

1. PPT手册的每张标准表，都有唯一的Excel工作表；
2. PPT只解释字段和使用方法，不另建一套不同字段；
3. 厚度、宽度、单位、版本、状态均拆成独立字段；
4. 产品、模具、工位、零件和文件都能通过唯一键追溯；
5. 生产异常能够关联工单、产品、模具和工位；
6. 修机报告能够关联更换零件和试模记录；
7. 所有未经确认的示例数据都带 `EX-` 或“示例”标记。
