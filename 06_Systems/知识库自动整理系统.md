# 知识库自动整理系统

> 这是 llmwiki 在当前系统里的落点：把新增内容增量整理成稳定结构，再清理旧入口。

## 目标
- 把 `_inbox` 里的新内容分流到正式结构树
- 把“临时入口 / 兼容壳 / 旧路径”收口到唯一 canonical 页面
- 保持 Obsidian 里的语义链接干净、稳定、可维护
- 让自动整理成为每日增量任务，而不是年底大扫除

## 推荐流程
1. **收集**：扫描当天新增/修改笔记
2. **分类**：判断它属于 `entity / concept / comparison / note / workflow`
3. **归位**：移动到 `02_Areas / 03_Resources / 04_Permanent / 05_MOC / 06_Systems` 中的对应位置
4. **连边**：补 wikilinks，确保每个稳定页至少有 2 个有效相关页
5. **收口**：把旧入口改链后删除，不保留长期双轨
6. **验证**：检查孤儿页、断链、重复页、过长页、过时页

## 这套系统的硬规则
- **唯一入口**：同一主题只保留一个正式入口
- **先改链后删壳**：没确认没有引用之前，不删旧页
- **不动原始材料**：raw / inbox 只作为输入层
- **索引只收稳定页**：时间页、日报、周计划不要塞进全局索引
- **旧页面要么迁移，要么归档，要么删除**，不要长期悬挂

## 适合自动整理的内容
- 公司产品知识
- 图纸与关键尺寸说明
- 材料型号对照
- 产品单重表
- 质量审查记录
- 计划/复盘生成内容
