# 鑫犇电子管理体系待确认清单 V2.0

> 在正式冻结新版PPT、流程图和RACI前，请由公司负责人逐项确认。未确认项目在PPT中统一显示为“待确认/以正式授权文件为准”。

| 编号 | 事项 | 需要确认的内容 | 影响 |
|---|---|---|---|
| C01 | 组织架构 | 是否使用董事长/总经理/营运部/生产/品质/采购/仓储/行政/财务/技术等名称 | 组织图、职责页 |
| C02 | 最高经营负责人 | 日常经营和跨部门裁决由谁承担 | 授权矩阵、异常升级 |
| C03 | 品质放行权 | 品质是否有独立最终放行权；让步由谁批准 | 质量异常流程 |
| C04 | 技术职能 | 技术/工程是否独立存在，还是由生产/品质兼任 | 订单评审、变更、模具 |
| C05 | 订单承诺 | 谁批准客户订单、交期、价格或特殊要求 | 订单评审流程 |
| C06 | 采购权限 | 采购是否独立；供应商选择和采购批准是否分离 | 采购到付款 |
| C07 | 仓储权限 | 收货、验收、入库、发料、出货的实际岗位分工 | 物料流程 |
| C08 | 付款权限 | 财务审核与最终批准人；金额分级是否存在 | 采购付款、授权矩阵 |
| C09 | 兼岗安排 | 哪些岗位由同一人兼任；如何补充复核控制 | 内控和RACI |
| C10 | 文件控制 | 文件编号、版本、批准、生效、作废、回收由谁维护 | 文件生命周期 |
| C11 | 记录保存 | 订单、质量、采购、财务、设备、模具等记录的保存位置和期限 | 记录生命周期 |
| C12 | 客诉时限 | 客诉接收、临时回复、正式回复、关闭的目标时间 | 客诉闭环 |
| C13 | 异常分级 | 一级/二级/三级定义和各级响应时间 | 异常升级 |
| C14 | 管理会议 | 经营会议、生产协调会、质量会议的频率、主持人和纪要责任人 | 管理闭环 |
| C15 | 关键指标 | 交付、质量、采购、库存、现金、整改等指标是否采用 | 管理看板 |
| C16 | 模具设备责任 | 台账、维修、状态确认、恢复使用批准分别由谁负责 | 资源状态流程 |
| C17 | 安全环保责任 | 行政、生产、设备和管理层的实际责任边界 | 安全应急流程 |
| C18 | 信息权限 | 客户图纸、报价、工艺、质量和人事资料的管理员及审批人 | 信息权限流程 |

## 冻结规则

- C01—C09未确认：只能输出“建议职责模型”，不能写成现行组织事实。
- C10—C15未确认：流程图可以表达控制逻辑，但不能写死金额、时限、保存年限和会议频率。
- C16—C18未确认：只能写责任接口和升级原则，不能指定具体岗位。
- 公司确认后，需将确认结果转入正式授权矩阵、部门职责表和受控文件清单。
